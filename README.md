## 🧱 Tech Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3**
- **Framer Motion** — smooth reveals, counters, transitions
- **Swiper JS** — vehicle image carousels & reviews slider
- **React Hook Form** — direct WhatsApp booking enquiry generator
- **Lucide React** + **React Icons**

## 🚀 Getting Started

```bash
npm install      # install dependencies
npm run dev      # dev server
npm run build    # production build
npm run preview  # preview production build
```
